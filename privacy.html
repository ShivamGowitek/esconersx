Light Lag

Privacy policy

Effective 5 November 2026.

This policy covers Light Lag Pipeline, a private tool that manages the Light Lag YouTube channel. It is used only by the channel's operator, with the operator's own Google account. It does not offer sign-in to anyone else, and this website does not use cookies, analytics or forms.

Google user data the app accesses

With the operator's consent through Google's sign-in screen, the app uses these permissions on the operator's account:

  • YouTube upload and account management: to upload videos and thumbnails, set their titles, descriptions, tags and schedule, and hold a video private if a problem is found.
  • YouTube read-only: to confirm the channel and upload status, and to read public search results and view counts for topic research.
  • YouTube Analytics read-only: to read the channel's views, watch time, audience retention, subscribers gained, impressions and click-through rate.

How the data is used

The data is used only to publish the channel's videos, report on their performance, and inform future topic choices. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The sign-in token is stored on the operator's own computer, in a folder restricted to the operator's Windows user. Analytics are stored in a local database on the same computer. Neither is stored on any server run by this project.

Sharing

Google user data is not sold and is not used for advertising. It is shared with one service provider, for one purpose: channel performance summaries, containing video titles and aggregate statistics, are sent to Google's Gemini API to help plan future videos. The app uses Gemini's free tier, under which Google may use submitted content to improve its products. The analytics are aggregates; the app does not receive personal information about viewers.

Retention and removal

Data is kept while the channel is operated. The operator can delete it at any time by deleting the local files, and can revoke the app's access at Google account permissions.

YouTube and Google

The app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
